# Lapwatch

A stopwatch and timer in a single web page. No install and no dependencies.

**[Try it live](https://john-pat10.github.io/lapwatch/)**

- **Stopwatch:** type what you're doing, press Lap to record splits and pace, and the fastest and slowest laps are flagged once you have three
- **Timer:** presets from 30 seconds to 1 hour, +1 minute, and an optional chime when time is up
- **History:** finished sessions are saved in your browser
- **Keyboard:** `Space` starts or pauses, `R` resets

Built with plain HTML, CSS and JavaScript. To run it locally, open `index.html` in any browser.
